# DroidOneX
A customizable PlayStation 1 emulator project for Android, focused on performance, controller support, and retro gaming.

🎮 DroidOneX — Relive the Classics

DroidOneX is an Android emulator project developed by a solo Brazilian developer with one mission: bringing back the nostalgia of classic PlayStation gaming while delivering a comfortable, convenient, and enjoyable experience for everyone.

Released in 1994, Sony's original PlayStation — widely known as the PlayStation 1, PS1, PSX, or Play 1 — became one of the most iconic and successful video game consoles in history. Today, finding an original console in good working condition can be increasingly difficult. DroidOneX aims to make these timeless gaming experiences more accessible on modern Android devices.

✨ Features

- Classic PlayStation Gaming: Relive the games that defined a generation.
- Advanced Configuration Options: Customize the emulator to suit your personal preferences.
- Advanced Controller Mapping: Configure physical controllers for a more comfortable gaming experience.
- Customizable Touchscreen Controls: Multiple touchscreen settings designed to improve comfort, accessibility, and gameplay.
- Multiple Game Formats: Support for CHD, BIN, CUE, BIN/CUE, and ISO files, as well as supported compressed archives such as ZIP and 7z.
- Practical User Interface: A straightforward interface designed to make navigating your game library easier.
- Performance-Focused Experience: Built around DuckStation technology, with an emphasis on optimization, customization, and smooth gameplay.
- BIOS Configuration: A configurable BIOS system that allows users to select a compatible BIOS when needed.

⚡ Performance and Compatibility

DroidOneX builds upon technology from DuckStation, a PlayStation 1 emulator, and aims to deliver an enhanced, highly configurable experience on Android.

The project focuses on performance, usability, and compatibility across a range of devices. Actual performance and game compatibility may vary depending on the device's hardware, Android version, emulator settings, and individual game.

The long-term goal is to provide the best possible performance while maintaining a practical and comfortable gaming experience.

📋 Minimum Requirements

- Processor (CPU): 1.5 GHz minimum.
- Architecture: Supports ARMv7 (32-bit), AArch64 (64-bit), or x86_64.
  - Important Note: 64-bit devices are strongly recommended. Although the application has historically supported 32-bit systems, performance is significantly more demanding on these devices, and faster processors are required to avoid stuttering.
- RAM: At least 2 GB (to run the operating system and emulator smoothly).
- Graphics (GPU): OpenGL ES 3.0 or Vulkan support.
- Operating System: Android 7.0 (Nougat) or later.

💡 Performance Tip

If your device is close to the minimum requirements, open the DuckStation video settings and set the renderer to Vulkan, if available, and keep the game's internal resolution at 1x (native resolution).

Increasing the internal resolution to 2x or higher, rendering at 4K, or enabling demanding graphics filters will require a considerably more powerful device.
